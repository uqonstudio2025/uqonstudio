# Nama Projek
Deskripsi ringkas mengenai projek ini, termasuk tujuan dan fungsinya.
## Pemasangan
Langkah-langkah untuk memasang projek:
1. Clone repositori: git clone https://github.com/nama-pengguna/nama-projek.git
2. Masuk ke direktori projek:  cd nama-projek
3. Pasang kebergantungan:  yarn install
## Cara Penggunaan
Panduan ringkas mengenai cara menjalankan projek: yarn start
